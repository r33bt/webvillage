# Video and motion (B14)

Product tour cards (screenshot + play button + presenter bubble), short muted loops of real UI, reveal-on-scroll with
stagger. Motion follows `design-craft/wow-bar.md` M1–M4 and must pass S1–S4: content is in the DOM without
JavaScript, `prefers-reduced-motion` is respected, Core Web Vitals are checked. Lottie or Rive only for the kit's own
illustrations. YouTube embeds use a lite facade (thumbnail first, iframe on click). For whiteboard explainers see
`/scribe-board`.
