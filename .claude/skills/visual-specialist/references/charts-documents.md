# Charts and primary documents (B7, B8)

**B7 · Data visuals.** The site's own real data as charts (load the `dataviz` skill first): light, one accent,
labelled directly, start and end labels on the axis. A chart counts as the hero on data pages and inside product UI
art. Never illustrative numbers: if the data is missing, the chart is not drawn. Inline SVG with ≥ 6 shapes counts on
its own; a chart built from HTML gets `data-visual="chart"`. Guides: the charts-led doctrine (a guide's own cited
figures as the primary visual) stays where a site has adopted it.

**B8 · Primary documents.** Cropped, credited facsimiles of the actual source (gazette page, annual-report table, a
form) where its terms allow. Editorial and legal sites' strongest visual. Never a document that could be mistaken
for the official one on a page where users might act on it (scam-lookalike risk).
